## 0. 拼命的企鹅
一只企鹅在爬山，每隔一段路都会遇到一块石头。第 1 块石头重量是 a，每往上走一段路，石头重量就会变成上一段的平方。企鹅可以选择把某些石头捡起来，最后把捡到的石头重量相乘。

它怎样捡石头，才能得到重量乘积恰好是 a 的 b 次方的石头？（比如 b = 173 时， 要捡哪些石头？）

### 一、列举
- 第一块：a
- 第二块：a^2
- 第三块：a^4
- ...
- 第n块：a^2^n-1
### 二、核心逻辑
将b拆为2的幂次之和，将b转为二进制。

**当b = 173时**
- 173 = 128 + 32 + 8 + 4 + 1 = 2^7 + 2^5 + 2^3 + 2^2 + 2^0
- 数字为7,5,3,2,0,对应的石头是8,6,4,3,1。

### 三、结果
**答案：8,6,4,3,1**

## 4. 不合群的数字
在一个数组中，所有数字都出现了偶数次，只有两个数字出现了奇数次，请聪明的你帮我看看以下的代码是如何找到这两个数字的呢？

```c
void findUndercoverIDs(int nums[], int size) {
    int xorAll = 0,id_a = 0,id_b = 0;
    for (int i = 0; i < size; i++) {
        xorAll ^= nums[i];
    }
    int diffBit = xorAll & -xorAll;
    for (int i = 0; i < size; i++) {
        if(nums[i] & diffBit){
            id_a ^= nums[i];
        } else {
            id_b ^= nums[i];
        }
    }
    printf("These nums are %d %d\n", id_a, id_b);
}
```
### 一、代码分析

设A和B为出现奇数次的两个数字
- 第一个for(...):
  - xorAll ^= nums[i];遍历数组，偶数次出现的数组在异或中相互抵消变为0，xorAll剩下的即为A^B。
- int diffBit = xorAll & -xorAll：
  - 用diffBit提取出xorAll中最右侧的1,A和B在二进制中至少有两位是不同的。
- 第二个for(...):
  - 用上一步中的diffBit将A和B分为两类id_a和id_b,再在这两类中用异或找出出现奇数次的A和B。

**输出：A B**

## 6. const 与指针：谁能动，谁不能动？
```c
struct P {
    int x;
    const int y;
};

int main() {
    struct P p1 = { 10, 20 }, p2 = { 30, 40 };
    const struct P p3 = { 50, 60 };
    struct P* const ptr1 = &p1;
    const struct P* ptr2 = &p2;
    const struct P* const ptr3 = &p3;
    return 0;
}
```
说说下列操作是否合法，并解释原因：

```test
ptr1->x = 100, | ptr2->x = 300, | ptr3->x = 500

ptr1->y = 200, | ptr1 = &p2, | ptr2->y = 400

ptr2 = &p1, | ptr3->y = 600, | ptr3 = &p1
```
### 一、核心逻辑
- const 在 * 左边（如 const struct P* ptr）：表示指针指向的对象是常量，不能通过指针修改数据。
- const 在 * 右边（如 struct P* const ptr）：表示指针本身是常量，不能修改指针的指向（不能指向别的变量）。
- 结构体内部的 const：struct P { const int y; }; 意味着无论该结构体变量是不是 const，它的成员 y 永远不能被修改。

### 二、逐条分析
**1. ptr1->x = 100,合法**
- ptr1 锁的是指针地址。指针指向 p1，而 p1 是一个普通变量（非 const），成员 x 也是普通 int。指针本身是常量不影响修改它指向的数据。

**2. ptr2->x = 300,非法**
- ptr2 是”指向常量的指针“。虽然p2本身是普通对象，但ptr2把p2视为只读，不能通过ptr2修改数据。

**3. ptr3->x = 500，非法**
- ptr3全锁，并且指向的p3本身也三const对象。

**4. ptr1->y = 200,非法**
- 结构体定义中y是const int。

**5. ptr1 = &p2,非法**
- ptr1的指针地址已锁，不能修改ptr1的指针地址。

**6. ptr2->y = 400，非法**
- y自带const不能改，并且prt2是“指向常量的指针”。

**7. ptr2 = &p1,合法**
- ptr2是“指向常量的指针”，不限制指针改地址。

**8. ptr3->y = 600,非法**
- ptr3全锁，并且y自带const。

**9. ptr3 = &p1，非法**
- ptr3全锁。

- 进入 `func()`：j 为107。执行 `j += g`（即 107 + 3）。
- 此时 j = 110。`arr[0] `被赋值为 110 + 1 = 111。
- ASCII 码 111 对应的字符是 'o'。
- `printf`打印出`hello linux`。

## 10. 拼接 排序 去重
本题要求你编写以下函数，不能改动 main 函数里的代码。实现对 arr1 和 arr2 的拼接、排序和去重。你需要自行定义 result 结构体并使用 malloc 手动开辟内存。

```c
int main() {
    int arr1[] = { 6, 1, 2, 1, 9, 1, 3, 2, 6, 2 };
    int arr2[] = { 4, 2, 2, 1, 6, 2 };
    int len1 = sizeof(arr1) / sizeof(arr1[0]);
    int len2 = sizeof(arr2) / sizeof(arr2[0]);

    struct result result;
    your_concat(arr1, len1, arr2, len2, result);
    print_result(result);
    your_sort(result);
    print_result(result);
    your_dedup(result);
    print_result(result);
    free(result.arr);
    return 0;
}
```
### 一、代码
```c
#include <stdio.h>
#include <stdlib.h>

// 1. 定义结构体
struct result {
    int *arr; // 动态数组指针
    int len;  // 有效元素个数
};

// 2. 打印函数
void print_result(struct result result) {
    for (int i = 0; i < result.len; i++) {
        printf("%d ", result.arr[i]);
    }
    printf("\n");
}

// 3. 拼接函数
void your_concat(int arr1[], int len1, int arr2[], int len2, struct result *result) {
    // 分配内存：长度为 len1 + len2
    result->arr = (int *)malloc((len1 + len2) * sizeof(int));
    if (result->arr == NULL) {
        printf("Memory allocation failed!\n");
        exit(1);
    }
    
    // 拷贝 arr1
    for (int i = 0; i < len1; i++) {
        result->arr[i] = arr1[i];
    }
    // 拷贝 arr2
    for (int i = 0; i < len2; i++) {
        result->arr[len1 + i] = arr2[i];
    }
    result->len = len1 + len2;
}

// 4. 排序函数（冒泡排序）
void your_sort(struct result *result) {
    for (int i = 0; i < result->len - 1; i++) {
        for (int j = 0; j < result->len - 1 - i; j++) {
            if (result->arr[j] > result->arr[j + 1]) {
                // 交换
                int temp = result->arr[j];
                result->arr[j] = result->arr[j + 1];
                result->arr[j + 1] = temp;
            }
        }
    }
}

// 5. 去重函数（基于排序后的数组，双指针原地压缩）
void your_dedup(struct result *result) {
    if (result->len <= 1) return; // 长度0或1无需去重

    int j = 0; // 慢指针，指向去重后数组的最后一个有效元素
    for (int i = 1; i < result->len; i++) { // 快指针，遍历整个数组
        if (result->arr[i] != result->arr[j]) {
            j++;
            result->arr[j] = result->arr[i]; // 将不重复的元素移到前面
        }
    }
    // 更新去重后的有效长度
    result->len = j + 1;
}

// 6. 主函数（轻微修正了传参，保证正确运行）
int main() {
    int arr1[] = { 6, 1, 2, 1, 9, 1, 3, 2, 6, 2 };
    int arr2[] = { 4, 2, 2, 1, 6, 2 };
    int len1 = sizeof(arr1) / sizeof(arr1[0]);
    int len2 = sizeof(arr2) / sizeof(arr2[0]);

    struct result result;
    // 修正：传入 &result，让函数能修改到 main 里的变量
    your_concat(arr1, len1, arr2, len2, &result); 
    
    print_result(result); // 打印拼接后的数组
    your_sort(&result);
    print_result(result); // 打印排序后的数组
    your_dedup(&result);
    print_result(result); // 打印去重后的数组
    
    free(result.arr);     // 释放动态分配的内存
    return 0;
}
```



## 11. 指针魔法
用你智慧的眼睛，透过这指针魔法的表象，看清其本质：

```c
void magic(int(*pa)[6], int** pp) {
    **pp += (*pa)[2];
    *pp = (*pa) + 5;
    **pp -= (*pa)[0];
    *pp = (*pa) + ((*(*pa + 3) & 1) ? 3 : 1);
    *(*pp) += *(*pp - 1);
    *pp = (*pa) + 2;
}
int main() {
    int a[6] = { 2, 4, 6, 8, 10, 12 };
    int* p = a + 1,** pp = &p;
    magic(&a, pp);
    printf("%d %d\n%d %d %d\n%d %d\n",*p,**pp,a[1],a[2],a[3],a[5],p-a);
    return 0;
}
```
### 一、输出结果
```test
6 6
12 6 8
10 2
```
### 二、代码分析
- `a`：int数组。
- `p`：指向a[1]。

**magic函数**

1. `**pp += (*pa)[2];`
- `**pp`：pp指向p，*pp 就是 p，**pp 就是 *p,*p为a[1]。
- `(*pa)[2]`：(*pa)为&a[0],这是a[2]。
- `a[1] += a[2]`：a[1]为10。
- **数组**：{2, 10, 6, 8, 10, 12}。
2. `*pp = (*pa) + 5;`
- `*pp`：为p。
- `(*pa) + 5`：*pa为&a[0],+ 5为&a[5]。
- `p = &a[5]`：p指向a[5]。
3. `**pp -= (*pa)[0];`
- `**pp`：为*p，指向a[5]。
- `(*pa)[0]`：为a[0]。
- `a[5] -= a[0]`：a[5]为10。
- **数组**：{2, 10, 6, 8, 10, 10}。
4. `*pp = (*pa) + ((*(*pa + 3) & 1) ? 3 : 1);`
- `*pp`：为p。
- `(*pa)`：为a[0]。
- `*(*pa + 3)`：a[3],8。
- `8 & 1`：按位与运算，返回0。
- `((0) ? 3 : 1)`：返回1。
- `p = (*pa) + 1`：修改p指向，指向&a[1]。
5. `*(*pp) += *(*pp - 1);`
- `*(*pp)`：*pp为p，*p为a[1]。
- `*(*pp - 1);`：&a[1]-1为&a[0]，解引用为a[0]。
- `a[1] += a[0]`：a[1]为12。
- **数组**：{2, 12, 6, 8, 10, 10}。
6. `*pp = (*pa) + 2;`
- `*pp`：p。
- `(*pa) + 2`：&a[2]。
- `p = &a[2]`：p指向&a[2]。

此时数组a={2, 12, 6, 8, 10, 10}，p指向&a[2]，pp指向p。

**回main函数**

## 12. 奇怪的循环
你能看明白这个程序怎样运行吗？试着理解这个程序吧！

```c
union data {
    void**** p;
    char arr[20];
};
typedef struct node {
    int a;
    union data b;
    void (*use)(struct node* n);
    char string[0];
} Node;
void func2(Node* node);

void func1(Node* node) {
    node->use = func2;
    printf("%s\n", node->string);
}
void func2(Node* node) {
    node->use = func1;
    printf("%d\n", ++(node->a));
}
int main() {
    const char* s = "Your journey begins here!";
    Node* P = (Node*)malloc(sizeof(Node) + (strlen(s) + 1) * sizeof(char));
    strcpy(P->string, s);
    P->use = func1;
    P->a = sizeof(Node) * 50 + sizeof(union data);
    while (P->a < 2028) {
        P->use(P);
    }
    free(P);
    return 0;
}
```
### 一、输出结果
```test
Your journey begins here!
2025
Your journey begins here!
2026
Your journey begins here!
2027
Your journey begins here!
2028
```
### 二、代码分析
**数据结构定义**

*1. `union data {...}`：*
- `void**** p`：四级指针，占8字节。
- `char arr[20]`：字符串，占20字节。
- __联合体大小__：取最大成员20字节，要8字节对齐，取24字节。

*2. `typedef struct node`：*
- `int a`：4字节，由于内存对齐，填充4字节。
- `union data b;`：24字节，偏移量为8。
- `void (*use)(struct node* n);`：函数指针，8字节，偏移量为32。
- `char string[0]`：柔性数组，不占结构体空间，偏移量为40。
- __结构体大小__：40字节。

**函数定义**

- `void func1`：把下次要执行的函数改为func2,打印字符串。
- `void func2`：递增a并打印，同时把把下次要执行的函数改为func1。

**main函数**
```test
    Node* P = (Node*)malloc(sizeof(Node) + (strlen(s) + 1) * sizeof(char));
    strcpy(P->string, s);
```
- 第一行：申请了40 + 26 = 66字节的连续内存，P指向内存的头。
- 第二行：P->string 指向偏移量为40的位置，将字符串s拷贝到P->string指向的位置。

- `P->use = func1;`：函数指针指向func1。
- `P->a = sizeof(Node) * 50 + sizeof(union data);`：将P->a赋为40 * 50 + 24 = 2024。
- `while循环`：函数func1和func2轮流执行，++a和字符串s轮流打印，在a为2028时停止。
