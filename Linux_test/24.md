## 0. 聪明的吗喽
一个小猴子边上有 100 根香蕉，它要走过 50 米才能到家，每次它最多搬 50 根香蕉，（多了就拿不动了），它每走 1 米就要吃掉一根，请问它最多能把多少根香蕉搬到家里。

（提示：他可以把香蕉放下往返走，但是必须保证它每走一米都能有香蕉吃。也可以走到 n 米时，放下一些香蕉，拿着 n 根香蕉走回去重新搬 50 根。）
### 一、分析
- 吗喽每次最多搬50根，总共有100根，所以至少要搬3次。
- 要把100根消耗到50根（一次搬完），50 / 3 = 16.33，取整为16m。
- 消耗3 * 16 = 48根，剩下100 - 48 = 52根。
- 带50根走1m，放下48根，回去1m搬2根再回到17m处，此时有49根。
- 带49根，走到终点，剩下49 - (50 - 17) = 16根。
### 二、结论
- 最多能把**16根**香蕉带到家。

## 3. 1.1 - 1.0 != 0.1
为什么会这样，除了下面给出的一种方法，还有什么方法可以避免这个问题？

```c
int main() {
    float a = 1.0, b = 1.1, ex = 0.1;
    printf("b - a == ex is %s\n", (b - a == ex) ? "true" : "false");
    int A = a * 10, B = b * 10, EX = ex * 10;
    printf("B - A == EX is %s\n", (B - A == EX) ? "true" : "false");
}
```
### 一、输出结果
```test
b - a == ex is false
B - A == EX is true
```
### 二、核心思想
- 计算机底层为二进制，只能精确表示分母为2的幂次的分数。
- 而十进制小数转换成二进制为无限循环小数，取一个非常接近的近似值。

### 三、代码分析
- `float`：a，b和ex均为无限循环小数。
- a + b一定不为ex。
- `int`：这一行将a，b和ex均*10,并且强转为int类型，截断小数部分。
- A + B可以为EX。

### 四、解决方法
- 既然无法绝对相等，那就定义一个及小的误差范围，只要两数差值在范围内，就认为他们相等。
```c
#include<stdio.h>
#include<math.h>

int main(){
    float a = 1.0, b = 1.1, ex = 0.1;
    if(fabs(fabs(b - a) - ex) < 1e-6){
        printf("true\n");
    }else{
        printf("false\n");
    }
}
```
- `fabs`：求浮点数绝对值的函数。
- `fabs(fabs(b - a) - ex) < 1e-6`：当a和b的差的绝对值小于0.000001,则判断为真。
- `if`：判断为真，视为两个数相等。



## 4. 听说爱用位运算的人技术都不太差
解释函数的原理，并分析使用位运算求平均值的优缺点。

```c
int average(int nums[], int start, int end) {
    if (start == end)
        return nums[start];
    int mid = (start + end) / 2;
    int leftAvg = average(nums, start, mid);
    int rightAvg = average(nums, mid + 1, end);
    return (leftAvg & rightAvg) + ((leftAvg ^ rightAvg) >> 1);
}
```
### 一、核心思想
用`(x & y) + ((x ^ y) >> 1)`计算x和y的平均值。
- 设`x = 5`,二进制为`0101`；`y = 7`,二进制为`0111`。
- `(x & y)`：0101 & 0111 = 0101，输出为5。
- `((x ^ y) >> 1)`：0101 ^ 0111 = 0010 , 0010 >> 1 为 0001，输出1。
- `(5 + 1)`：输出6。
- `验证`：(5 + 7) / 2 = 5 + 1 = 6。 

### 二、代码分析
- 设输入为`nums[8] = {1,2,3,4,5,6,7,9,}`
- 分成两半`{1,2,3,4,}` , `{5,6,7,9,}`
- 左右两边再分，最后`leftAvg`为2.5,取整为2,`rightAvg`为6.75,取整为6。
- 返回合并的平均值，为4。

### 三、位运算求平均值优缺点
**优点：**

- 防止整型溢出。
- 执行效率高。

**缺点**

- 负数会算错。
- 可读性差。

## 11. 猜猜我是谁
在指针的迷宫中，五个数字化身为神秘的符号，等待被逐一揭示。

```c
int main() {
    void *a[] = {(void *)1, (void *)2, (void *)3, (void *)4, (void *)5};
    printf("%d\n", *((char *)a + 1));
    printf("%d\n", *(int *)(char *)a + 1);
    printf("%d\n", *((int *)a + 2));
    printf("%lld\n", *((long long *)a + 3));
    printf("%d\n", *((short *)a + 4));
    return 0;
}
```
### 一、输出结果
```c
0
2
2
4
2
```
### 二、代码分析
- `void *a[]`：这是一个指针数组，每个元素占 8 字节。在小端序下，这 5 个数字在内存中的排布（十六进制）如下：

a[0] (0x1000)：01 00 00 00 00 00 00 00

a[1] (0x1008)：02 00 00 00 00 00 00 00

a[2] (0x1010)：03 00 00 00 00 00 00 00

a[3] (0x1018)：04 00 00 00 00 00 00 00

a[4] (0x1020)：05 00 00 00 00 00 00 00

1. `printf("%d\n", *((char *)a + 1));`：`(char *)a`把数组首地址转为char*，步长1字节；`+ 1`把指针向后移动1字节，指向00,打印0。
2. `printf("%d\n", *(int *)(char *)a + 1);`：`(char *)a`转为char*；`(int *)`强转为int*；`*`解引用为1，1 + 1 = 2，打印2。
3. `printf("%d\n", *((int *)a + 2));`：`(int *)a`转为int*，步长为4；`+ 2`指针向后移动8字节，指向0x1008；读4字节`02 00 00 00`，打印2。
4. `printf("%lld\n", *((long long *)a + 3));`：`(long long *)a`转为long long*,步长为8字节；`+ 3`向后移动16字节，读8字节`04 00 00 00 00 00 00 00`，打印4。
5. `printf("%d\n", *((short *)a + 4));`：`(short *)a`转为short*,步长为2；`+ 4`向后移动8字节，读2字节`02 00`，打印2。
